# KhabarGanit (खबरगणित)
*हर ख़बर की कहानी, आँकड़ों की ज़ुबानी*

KhabarGanit is a modern digital broadsheet newspaper web application engineered with Next.js 15, Tailwind CSS, Lucide Icons, and interactive Google Translate localization. It renders an authentic, high-contrast, physical broadsheet newspaper layout with smooth 3D page-turn animations.

## ✨ Architectural Features

- **Classic Broadsheet Typography:** Playfair Display headline serif combined with high-contrast rules.
- **Realistic 3D Page Turn Animation:** 2.2-second smooth page-turning transition with multi-stage curl and shadow progression.
- **Edge-to-Edge Top Strip:** Localized date, edition identification, and Google Translate dropdown pinned to the far right with zero empty margins.
- **Domain-Specific Top 10 Digests:** Every edition includes a dedicated 10-point intelligence monitor and editorial column.
- **Multilingual Support:** Instant on-the-fly translation into 18+ regional and international languages via Google Translate.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/rajsh7/Khabarganit.git
cd Khabarganit

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
